# Day 27 — Team Roles & Responsibilities

## Project: AI Customer Support Agent

## 1. Team Structure

The AI Customer Support Agent requires collaboration between business, development, testing, and deployment roles. Agile practices are used to coordinate responsibilities and ensure that project tasks are completed according to sprint priorities.

## 2. Roles and Responsibilities

| Role | Primary Responsibility | Key Activities |
|---|---|---|
| Product Owner | Business direction | Defines requirements, priorities, and expected outcomes |
| Scrum Master | Agile process | Facilitates sprint planning, stand-ups, reviews, and removes blockers |
| AI/ML Developer | AI development | Develops RAG, embeddings, retrieval, prompts, and LLM integration |
| Backend Developer | Backend systems | Develops APIs, application logic, and service integrations |
| Frontend Developer | User interface | Develops customer support interface and user interaction |
| QA/Test Engineer | Quality assurance | Creates test cases, evaluates responses, and reports defects |
| DevOps Engineer | Deployment and infrastructure | Manages environments, deployment configuration, and operational setup |
| Technical Writer | Documentation | Maintains technical documentation, architecture notes, and project guides |

## 3. Role Interaction

The team follows a collaborative workflow:

Product Owner
↓
Requirements and Priorities
↓
Scrum Master
↓
Sprint Planning
↓
Development Team
↓
Code Review
↓
QA / Testing
↓
Deployment
↓
Sprint Review

## 4. Responsibility by Project Area

### Project Planning
- Product Owner defines business requirements.
- Scrum Master organizes sprint planning.
- Development team estimates task complexity.

### AI Development
- AI/ML Developer handles embeddings, retrieval, RAG, prompts, and LLM integration.
- Backend Developer handles APIs and system integration.

### User Experience
- Frontend Developer develops the customer support interface.
- AI/ML and Backend developers integrate the interface with the AI workflow.

### Testing
- QA/Test Engineer prepares test cases.
- Development team fixes identified issues.
- AI/ML Developer evaluates retrieval and response quality.

### Deployment
- DevOps Engineer prepares the deployment environment.
- Development and QA teams support deployment validation.

### Documentation
- Technical Writer maintains project documentation.
- Developers provide technical details for architecture and implementation documentation.

## 5. Team Collaboration Principles

- Responsibilities should be clearly assigned.
- Team members should communicate blockers early.
- Tasks should follow sprint priorities and dependencies.
- Code changes should go through version control and review.
- Testing should be performed before final delivery.
- Important project decisions should be documented.
- Team members should collaborate rather than work in isolated workflows.

## 6. Expected Team Outcome

The team should work together to deliver a reliable AI Customer Support Agent within the planned sprint timeline while maintaining code quality, testing standards, clear communication, and proper documentation.

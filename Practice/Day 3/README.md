## Professional Workflow

- Created a Git repository.
- Added project files.
- Made multiple meaningful commits.
- Used professional commit message conventions.
- Created a feature branch named `feature/python`.
- Worked on the feature branch.
- Pushed changes to GitHub.
- Merged feature branch into the main branch.
